# Публичный API (Swagger)

Интерактивная документация по спецификации `labs/lab2/gateway/openapi.yaml` (OpenAPI 3.0.3, 16 путей, 23 схемы). Кнопка «Try it out» отправляет запросы на выбранный сервер. На этом сайте выберите `http://localhost:3000/api/v1`, если стенд запущен локально. На развёрнутых стендах та же спецификация открывается в Swagger UI самого gateway (`/api/docs/` и `/k8s/api/docs/`), и там сервер по умолчанию указывает на текущий стенд.
