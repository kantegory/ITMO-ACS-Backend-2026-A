# ДЗ3: Тестирование API средствами Postman

## Файлы

- `ДЗ3_Фёдоров_Иван_БР1.1.postman_collection.json` - коллекция с комплексным сценарием и тестами.
- `RentEase_Local.postman_environment.json` - окружение с адресом локального API.

## Сценарий

Коллекция выполняет основной пользовательский процесс:

1. Проверка доступности приложения.
2. Регистрация арендодателя.
3. Вход арендодателя и получение JWT.
4. Создание объявления.
5. Регистрация арендатора.
6. Вход арендатора и получение JWT.
7. Получение списка объявлений.
8. Фильтрация объявлений.
9. Просмотр выбранного объявления.
10. Начало переписки с арендодателем.
11. Проверка диалога.

Тестовые пользователи и email создаются заново при каждом запуске коллекции. Это позволяет запускать сценарий повторно без очистки локальной базы H2.

## Запуск

Из каталога `БР1.1/Lab1` запустить API:

```powershell
mvn spring-boot:run "-Dspring-boot.run.profiles=local"
```

В Postman:

1. Импортировать environment `RentEase_Local.postman_environment.json`.
2. Выбрать окружение `RentEase Local`.
3. Импортировать коллекцию `ДЗ3_Фёдоров_Иван_БР1.1.postman_collection.json`.
4. Запустить коллекцию через **Run collection**.
5. Проверить, что все тесты завершились зелёными.

Дополнительно сценарий можно запускать из командной строки через Newman:

```powershell
newman run "БР1.1/hw3/ДЗ3_Фёдоров_Иван_БР1.1.postman_collection.json" `
  -e "БР1.1/hw3/RentEase_Local.postman_environment.json"
```
