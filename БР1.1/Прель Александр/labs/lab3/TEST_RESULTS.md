## Выявленные и исправленные проблемы запуска

1. Первый запуск остановился на `invalid mount path: 'noexec'`: YAML flow-list разбивал tmpfs-параметры по запятым. Строка `/tmp:rw,noexec,nosuid,size=16m` заключена в кавычки.
2. Следующий запуск был healthy внутри Docker, но API не отвечал на Mac. Gateway состоял только во внутренней сети; опубликованный порт не появился в Docker NetworkSettings. Первый Compose-тестовый прогон завершился на setup с `Timed out: Compose ready (fetch failed)`, все восемь сценариев не смогли начаться. Добавлена отдельная edge-сеть только для Gateway; 127.0.0.1:8090 стал доступен. Повторный полный прогон прошёл 8/8.
