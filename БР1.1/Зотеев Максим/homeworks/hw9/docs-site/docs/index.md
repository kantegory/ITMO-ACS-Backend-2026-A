# Сервис аренды недвижимости (Rental Platform)

Техническая документация микросервисного бэкенд-приложения, разработанного в рамках расширенного курса по бэкенд-разработке на Node.js в Университете ИТМО (группа **БР1.1**, Зотеев Максим).

## Назначение системы

Платформа реализует серверную часть сервиса долгосрочной аренды недвижимости (вариант №4):

- регистрация и JWT-аутентификация арендаторов (`tenant`) и арендодателей (`landlord`);
- управление каталогом объектов недвижимости, фотографиями, справочниками типов и удобств;
- фильтрация и сортировка объявлений по городу, району, цене, числу комнат и набору удобств;
- оформление, завершение и отмена сделок аренды с атомарным резервированием и сохранением снапшота условий;
- переписка участников сделки с автоматическими системными уведомлениями через **Transactional Outbox** и **RabbitMQ**.

## Состав сервисов

| Компонент | Порт | База данных | Ответственность |
|---|---|---|---|
| `api-gateway` | `8080` | — | Единая точка входа, маршрутизация `/api/v1/*`, сокрытие `/internal/*` |
| `identity-service` | `3001` | `identity` (PostgreSQL) | Регистрация, логин (bcrypt + JWT), профили, batch-get пользователей |
| `property-service` | `3002` | `property` (PostgreSQL) | Каталог, поиск, справочники, фотографии, оптимистическая блокировка доступности |
| `rental-service` | `3003` | `rental` (PostgreSQL) | Жизненный цикл сделок аренды, снапшоты, запись событий в `rental_outbox` |
| `rental-outbox` | — | `rental` (PostgreSQL) | Фоновый relay-процесс, перекладывающий события из `rental_outbox` в RabbitMQ |
| `messaging-service` | `3004` | `messaging` (PostgreSQL) | Чат по сделкам, подписка на `messaging.rental-events`, идемпотентные системные сообщения |
