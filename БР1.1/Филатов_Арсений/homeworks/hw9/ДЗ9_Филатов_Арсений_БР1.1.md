## 1. Цель

Задокументировать микросервисное приложение средствами Postman, OpenAPI и MkDocs.

## 2. Что сделано

Всё лежит в `labs/lab2` (отчёт только здесь).

**Postman:** коллекция `postman/Lab2_Gateway.postman_collection.json` — сценарий через gateway (регистрация, вход, компания, вакансия, резюме, отклик).

**OpenAPI:** у auth, catalog, jobseeker, employer, application UI `/openapi` и JSON `/openapi/json` (Elysia). Описание в `services/*/src/openapi.ts`.

**MkDocs:** `mkdocs.yml` + `docs/` (архитектура, OpenAPI, Postman, запуск).

```powershell
cd labs\lab2
pip install mkdocs-material
mkdocs serve
```

Сайт: `http://127.0.0.1:8000`.

## 3. Вывод

Документация собрана тремя средствами курса: коллекция Postman, живые OpenAPI-спеки сервисов, сайт MkDocs.
