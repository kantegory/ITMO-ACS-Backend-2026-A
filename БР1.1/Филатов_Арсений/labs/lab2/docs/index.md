# Job Search API

Микросервисный бэкенд сервиса поиска работы (вариант 2 курса). Код: каталог `labs/lab2`.

Публичный вход: **gateway** (`http://localhost:3000` или через kind Ingress `http://localhost:8080`).

| Сервис | Порт | Назначение |
|--------|------|------------|
| gateway | 3000 | прокси API |
| auth | 3001 | регистрация, вход, JWT |
| catalog | 3002 | отрасли, навыки, уровни |
| jobseeker | 3003 | профили и резюме |
| employer | 3004 | компании и вакансии |
| application | 3005 | отклики + события RabbitMQ |

Документация собрана средствами **MkDocs**, контракты API: **OpenAPI** у каждого сервиса, сценарии: **Postman**.
