## 1. Цель работы

Развернуть микросервисное приложение Job Search в Kubernetes по дизайну ДЗ7 и проверить оркестрацию (health, рестарт пода, Ingress).

## 2. Что развёрнуто

Контур: **kind** на Docker Desktop, кластер `lab2` (control-plane + worker).

Код и манифесты: `labs/lab2/k8s/`, конфиг: `labs/lab2/kind/`, скрипт: `labs/lab2/scripts/k8s-up.ps1`.

| Компонент | Как |
|-----------|-----|
| Образы | `docker build --target <svc> -t lab2/<svc>:local` + `kind load` |
| БД | Postgres 16 в кластере, 5 БД `lab2_*` |
| Очередь | RabbitMQ в кластере |
| Сервисы | auth, catalog, jobseeker, employer, application, gateway |
| Вход | ingress-nginx → Service gateway |
| URL | `http://localhost:8080` |

Запуск:

```powershell
Set-Location labs\lab2
.\scripts\k8s-up.ps1
curl http://localhost:8080/health
kubectl -n lab2 get all
```

## 3. Проверки

1. `GET http://localhost:8080/health` → `{"ok":true}`.
2. `kubectl -n lab2 get pods` — все Ready.
3. Удаление пода gateway: ReplicaSet создаёт новый, health снова отвечает.
4. Ingress на control-plane (`kind/ingress-controller-patch.yaml`), порты 8080/8443 с хоста.

## 4. Вывод

Приложение из lab2 поднято в Kubernetes (kind) с Ingress, Postgres, RabbitMQ и probes по дизайну ДЗ7.
