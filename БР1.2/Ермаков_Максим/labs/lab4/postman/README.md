# Проверка в Postman

Импортировать коллекцию и окружение из этой папки. Выбрать `Restaurant Booking Lab4 Server`.
В локальное значение `adminPassword` вручную внести пароль из серверного `.env`.
Не экспортировать заполненное окружение и токены, не делать с ними скриншоты.
Запустить всю коллекцию по порядку в Collection Runner с задержкой 500 мс.
Дата бронирования выбирается на семь дней вперёд; пароль нового тестового пользователя создаётся автоматически.
Сценарий создаёт ресторан, столик, меню, пользователя, бронь и отзыв; затем ждёт рейтинг 5 и один отзыв.

RabbitMQ не опубликован в интернет. На сервере можно проверить очередь:
`docker compose exec rabbitmq rabbitmqctl list_queues name consumers messages_ready messages_unacknowledged`

Коллекция подготовлена для дальнейшего использования. Фактическая проверка ЛР4 выполняется вспомогательным скриптом через Termius, а не в Postman.
