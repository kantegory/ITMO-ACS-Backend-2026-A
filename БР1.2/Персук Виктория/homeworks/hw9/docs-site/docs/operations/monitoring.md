# Мониторинг

Для приложения на сервере настроен стек наблюдаемости, который запускается рядом с приложением отдельным Docker Compose.

| Компонент | Назначение |
|-----------|------------|
| Prometheus | Сбор и хранение метрик |
| node-exporter | Метрики сервера: CPU, память, диск, сеть |
| blackbox-exporter | Проверка доступности всех компонентов приложения по HTTP и TCP |
| Loki | Хранение логов |
| Grafana Alloy | Сбор логов контейнеров и отправка их в Loki |
| Grafana | Дашборды и оповещения, порт 3030 |

## Дашборд

Дашборд Grafana состоит из трёх разделов.

1. Ресурсы сервера по метрикам node-exporter.
2. Состояние healthcheck каждого компонента приложения по данным blackbox-exporter.
3. Логи выбранного контейнера с фильтром ошибок по данным Loki.

## Оповещения

Если какой-либо компонент недоступен дольше минуты, Grafana отправляет письмо через SMTP Gmail. После восстановления приходит второе письмо о том, что проблема решена. Пароль приложения Gmail хранится в файле `.env`, который не попадает в репозиторий.
