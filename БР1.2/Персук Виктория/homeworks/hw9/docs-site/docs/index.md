# Платформа бронирования ресторанов

Веб-приложение для поиска ресторанов, бронирования столиков, просмотра меню и отзывов. Приложение разработано в рамках курса «Бэк-энд разработка» в ИТМО и построено на микросервисной архитектуре.

!!! info "Автор"
    Персук Виктория, 2026 г.

## Что умеет приложение

- Регистрация и вход пользователей с выдачей JWT-токена.
- Создание ресторанов владельцами и их проверка администратором.
- Управление столиками, меню и фотографиями ресторана.
- Бронирование столика с проверкой пересечения по времени.
- Отзывы с автоматическим пересчётом среднего рейтинга ресторана.
- Уведомления о регистрации, бронировании и смене статуса ресторана.

## Сервисы

| Сервис | Порт | База данных | Назначение |
|--------|------|-------------|------------|
| [api-gateway](services/api-gateway.md) | 3000 | нет | Единая точка входа для клиентов |
| [auth-service](services/auth-service.md) | 3001 | auth_db | Пользователи, роли, токены |
| [restaurant-service](services/restaurant-service.md) | 3002 | restaurant_db | Рестораны, кухни, фото, персонал |
| [reservation-service](services/reservation-service.md) | 3003 | reservation_db | Столики и бронирования |
| [menu-service](services/menu-service.md) | 3004 | menu_db | Меню и позиции меню |
| [review-service](services/review-service.md) | 3005 | review_db | Отзывы и рейтинг |
| [notification-service](services/notification-service.md) | 3006 | нет | Уведомления по событиям RabbitMQ |

## Используемые технологии

| Технология | Назначение |
|------------|------------|
| Node.js + TypeScript | Основной стек всех сервисов |
| Express | HTTP-сервер |
| TypeORM | ORM для PostgreSQL |
| routing-controllers | Декораторный подход к маршрутам |
| http-proxy-middleware | Проксирование запросов в API Gateway |
| axios | Синхронные HTTP-вызовы между сервисами |
| amqplib | Работа с RabbitMQ (публикация и потребление сообщений) |
| JWT | Аутентификация (общий секрет во всех сервисах) |
| bcryptjs | Хэширование паролей |
| class-validator | Валидация DTO |
| swagger-ui-express | Интерактивная документация API |
| Docker + Docker Compose | Контейнеризация и оркестрация |
| PostgreSQL 16 | СУБД (по одной БД на сервис) |
| RabbitMQ 3 | Брокер сообщений |

## Быстрый старт

```bash
cd labs/lab2
docker compose up -d --build
curl http://localhost:3000/health
```

После запуска API доступно по адресу `http://localhost:3000/api/v1`, а Swagger UI каждого сервиса по адресу `http://localhost:<порт>/api/docs`.
