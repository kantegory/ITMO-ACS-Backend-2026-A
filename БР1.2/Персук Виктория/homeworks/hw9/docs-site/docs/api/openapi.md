# Спецификация OpenAPI

Все публичные и внутренние эндпоинты приложения описаны в едином файле OpenAPI 3.0 [`openapi.yaml`](openapi.yaml). Ниже он отображается в Swagger UI. Запросы можно отправлять прямо со страницы, если приложение запущено локально и выбран сервер `http://localhost:3000/api/v1`.

!!! tip "Авторизация"
    Выполните `POST /auth/login`, скопируйте `accessToken` из ответа, нажмите **Authorize** и вставьте токен в поле `bearerAuth` без слова `Bearer`.

!!! note "Внутренние эндпоинты"
    Маршруты `/internal/*` вызываются сервисами друг у друга и не проксируются через api-gateway. Снаружи они недоступны.
