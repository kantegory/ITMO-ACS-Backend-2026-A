# Справочник API

Swagger UI на шлюзе находится по пути `/api/v1/swagger-ui/index.html`. В меню можно переключаться между сервисами и просматривать параметры запросов, схемы данных и коды ответов.

| Микросервис | Группы маршрутов | OpenAPI JSON на шлюзе |
| --- | --- | --- |
| `user-service` | Вход, пользователи и профили | `/api/v1/docs/user` |
| `media-service` | Видео | `/api/v1/docs/media` |
| `training-service` | Упражнения, тренировки, теги и типы | `/api/v1/docs/training` |
| `blog-service` | Статьи, категории и комментарии | `/api/v1/docs/blog` |
| `progress-service` | Прогресс и сессии тренировок | `/api/v1/docs/progress` |

## Использование в Postman

1. Откройте путь OpenAPI нужного сервиса на адресе шлюза и сохраните ответ в файл JSON.
2. В Postman нажмите **Import** и импортируйте файл как **Postman Collection**.
3. Укажите адрес своего шлюза в переменной коллекции `baseUrl` и убедитесь, что итоговые URL запросов содержат `/api/v1` один раз.
4. Для первого запроса можно использовать `GET {{baseUrl}}/api/v1/exercises?page=0&size=20`. Для защищённых запросов настройте [Bearer-токен](auth.md).

## Примеры маршрутов

В таблице указаны полные пути при обращении через шлюз. Значение в фигурных скобках заменяется фактическим идентификатором.

| Сервис | Запрос | Назначение |
| --- | --- | --- |
| `user-service` | `POST /api/v1/auth/login` | Войти и получить токены |
| `user-service` | `GET /api/v1/profiles/me` | Получить профиль текущего пользователя |
| `media-service` | `GET /api/v1/videos/{videoId}` | Получить сведения о видео |
| `training-service` | `GET /api/v1/exercises` | Получить страницу упражнений |
| `training-service` | `GET /api/v1/trainings/{trainingId}` | Получить тренировку по идентификатору |
| `blog-service` | `GET /api/v1/articles` | Получить список статей |
| `progress-service` | `GET /api/v1/training-sessions` | Получить список тренировочных сессий |
| `progress-service` | `GET /api/v1/training-sessions/{sessionId}/exercises` | Получить упражнения выбранной сессии |

Чтобы изучить конкретную операцию, откройте её в Swagger UI. В разделе **Parameters** показаны параметры пути и строки запроса. Если операция принимает JSON, раздел **Request body** показывает схему тела. В разделе **Responses** указаны ожидаемые коды и форматы ответов.

## Пример набора запросов в Postman

| Запрос | Настройка |
| --- | --- |
| Каталог упражнений | Метод `GET`, путь `/api/v1/exercises`, параметры `page=0` и `size=20` во вкладке **Params** |
| Вход | Метод `POST`, путь `/api/v1/auth/login`, во вкладке **Body** выбрать **raw** и **JSON**, передать имя и пароль тестовой учётной записи |
| Мой профиль | Метод `GET`, путь `/api/v1/profiles/me`, во вкладке **Authorization** выбрать **Bearer Token** и указать `{{accessToken}}` |

После входа сохраните полученный токен в переменной `accessToken` для текущего окружения Postman. Если нужно передать коллекцию другому человеку, экспортируйте её в JSON с пустой переменной токена.
