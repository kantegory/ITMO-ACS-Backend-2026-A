# FitnessAPI

FitnessAPI - микросервисное приложение для работы с тренировками. Через API можно просматривать упражнения, работать с тренировками и записями о выполнении, управлять профилем и читать материалы блога.

| Микросервис | За что отвечает |
| --- | --- |
| `user-service` | Учётные записи, вход и профили |
| `media-service` | Работа с видео |
| `training-service` | Упражнения, тренировки, типы и теги |
| `blog-service` | Статьи, категории и комментарии |
| `progress-service` | Тренировочные сессии и прогресс пользователя |

Клиент отправляет запросы на один адрес шлюза. Шлюз выбирает микросервис по пути запроса. Swagger UI доступен по тому же адресу и даёт выбрать документацию каждого сервиса в меню.

Начните с [первого запроса к API](quickstart.md).

## Как пользоваться документацией

- [Быстрый старт](quickstart.md) поможет получить первую страницу упражнений и прочитать ответ API.
- [Авторизация](auth.md) описывает вход, доступ к своему профилю и обновление токена.
- [Справочник API](api.md) содержит примеры маршрутов и порядок импорта OpenAPI в Postman.

## Как обрабатывается запрос

Клиент обращается к общему адресу FitnessAPI. Например, запрос `GET /api/v1/exercises` шлюз передаёт в `training-service`, а `POST /api/v1/auth/login` - в `user-service`. Адрес клиента при этом остаётся адресом шлюза.

MkDocs содержит руководство с готовыми примерами. В Swagger UI можно посмотреть параметры конкретной операции и отправить запрос к запущенному приложению. В Postman можно сохранить запросы и повторно выполнять их с нужным адресом и параметрами.
