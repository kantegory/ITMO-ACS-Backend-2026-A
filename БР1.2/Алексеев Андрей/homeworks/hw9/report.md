# Задача

Подготовить Swagger/OpenAPI, коллекцию Postman и MkDocs для API авторизации.

# Исходные данные

API авторизации доступно через [Swagger UI](https://ab.pxdkxvan.lol/swagger-ui.html). Исходные материалы — `infra/semester2/docs/auth.md`, `auth-openapi.json` и коллекция в `infra/semester2/auth/postman`.

# Ход работы

Swagger UI показывает контракт из springdoc. Зафиксирован снимок OpenAPI, в котором описаны тела запросов и ответов регистрации, входа и обновления токена. Публичный префикс: /api/v1. Коллекция Postman создаёт уникальный тестовый аккаунт, проверяет неправильный пароль, выдачу JWT и ротацию refresh token.

MkDocs содержит инструкцию по запуску, настройку HTTPS, правила секретов, ссылки на OpenAPI и команды для Newman и k6.

# Проверка результата

MkDocs собран с --strict. Newman локально выполнил 5 запросов и 7 проверок без ошибок. Публичный Swagger доступен по HTTPS, /v3/api-docs вернул 200. Публичный прогон Newman через HTTPS дал тот же результат: 5 запросов, 7 проверок, 0 ошибок.

# Вывод

Схемы API, тесты и руководство описывают один и тот же контракт авторизации.
