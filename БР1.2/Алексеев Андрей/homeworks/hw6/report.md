# Задача

Автоматизировать сборку и доставку приложения на ВМ после изменения выделенной ветки.

# Ход работы

Workflow Auth release запускается на push в auth-vm. GitHub Actions собирает образ через BuildKit и присваивает ему полный SHA. Runner проверяет известный ключ SSH-сервера и передаёт образ потоком. Deploy SSH-ключ привязан к одной команде. Скрипт проверяет режим и формат SHA, блокирует параллельный выпуск, загружает образ, обновляет Compose и ждёт готовности.

Сквозная проверка вызывает регистрацию, вход и обновление токена через nginx. При ошибке workflow завершается с ненулевым кодом. Возврат к предыдущему приложению выполняется повторным выпуском последнего успешного образа. Том PostgreSQL сохраняется.
