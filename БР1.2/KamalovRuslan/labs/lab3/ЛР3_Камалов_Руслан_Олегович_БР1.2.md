## Цель

Я контейнеризировал сервисы FitFlow и собрал локальное окружение Docker Compose.

## Реализация

Для Node.js-приложений я использовал многостадийную сборку: зависимости и TypeScript собираются на build-стадии, а runtime содержит только необходимые файлы. Compose описывает сервисы, отдельные PostgreSQL БД, RabbitMQ и Nginx. Зависимости запуска контролируются health-check, конфигурация передаётся через `.env`, постоянные данные размещаются в volumes.

```text
docker compose --profile microservices up --build
docker compose --profile microservices ps
```

Я проверил обе конфигурации командами `docker-compose --profile monolith config --quiet` и `docker-compose --profile microservices config --quiet`. Обе завершились успешно. Сборка образов подготовлена, но не запускалась в текущем окружении, поскольку локальный Docker daemon выключен.

## Вывод

Я подготовил конфигурацию запуска полной системы одной командой с профилем microservices. Отдельно доступен профиль monolith; успешную сборку и runtime контейнеров необходимо подтвердить запуском.
