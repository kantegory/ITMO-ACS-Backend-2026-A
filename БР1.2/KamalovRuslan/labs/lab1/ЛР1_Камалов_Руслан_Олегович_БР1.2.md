## Цель

Я разработал монолитный REST API FitFlow на TypeScript, Node.js, Express, TypeORM и PostgreSQL.

## Реализация

В приложении я реализовал сущности и CRUD-маршруты согласно `docs/openapi.yaml`. Входные данные валидируются, пароли хешируются bcrypt, после входа выдаётся JWT. Middleware различает обычного пользователя и администратора. Пользователь работает только со своими планами и прогрессом. Ошибки возвращаются в едином JSON-формате. Swagger UI предоставляет интерактивную документацию.

Приложение состоит из модулей конфигурации DataSource, TypeORM-сущностей, HTTP-приложения, seed-данных и точки запуска. Реализованы пользователи, тренировки, планы, элементы планов, прогресс и статьи.

## Проверка

npm run typecheck

Компиляция завершилась без ошибок, 7 автоматических тестов прошли. Дополнительно я поднял временную локальную PostgreSQL и выполнил сквозной HTTP-сценарий. API вернул `health=ok`, создал пользователя, тренировку, план, запись прогресса и статью; агрегат прогресса вернул `completedWorkouts=1`, `totalMinutes=20`.
