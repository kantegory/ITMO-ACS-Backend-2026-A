# ДЗ10 · Нагрузка Ehrmann в k6

Скрипт `ehrmann.k6.js` запускает один профиль за прогон. Передайте полный URL backend, заканчивающийся `/api/v1`.

```sh
API_URL=https://backend.dev.ehrmann.assistant.metamentor.pro/api/v1 PROFILE=smoke \
  SUMMARY_FILE=smoke.json k6 run ehrmann.k6.js
```

Для профиля `backend` в тестовом окружении установите `API_URL`, `ACCESS_TOKEN`, `SESSION_ID` из тестовой сессии ADFS. Профиль последовательно повышает нагрузку на чтение чатов до 8 запросов/с. Стандартный ограничитель backend пропускает 100 запросов за 60 секунд на IP. Для проверки пиковой ступени на выделенном стенде используйте `RATE_LIMIT_HTTP=600` и дождитесь применения конфигурации. Включайте в анализ статус 429, если цель прогона — проверка лимита.

Для `PROFILE=ml` укажите `ML_URL` внутреннего ML Core. Запускайте генератор из сети, у которой есть доступ к ML Core. Профиль проверяет генерацию заголовка из тестовой истории с верхней ступенью 5 запросов за 10 секунд.

Каждый прогон сохраняет RPS, p95, p99, долю ошибочных ответов, проверки JSON и пропущенные итерации. Пороговые значения проверяются k6. Для анализа нагрузки на облачном стенде используйте [ЛР8](../../labs/lab8/README.md).
