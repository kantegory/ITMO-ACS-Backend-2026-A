# Ehrmann Assistant

Веб-ассистент отвечает на вопросы по базе знаний организации и показывает источники. Пользователь входит через ADFS, ведёт чаты и может добавлять файлы. Администратор управляет публикациями базы знаний, группами и правами доступа.
