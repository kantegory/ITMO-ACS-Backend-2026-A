# Нагрузка

Сценарии k6 лежат в каталоге `k6`.

Цели, от которых отталкивается тюнинг:

| Сценарий | Нагрузка | p95 | доля ошибок |
| --- | --- | --- | --- |
| Поиск ресторанов | 30 RPS | 400 мс | < 1% |
| Карточка и меню | 40 RPS | 250 мс | < 1% |
| Чтение от имени пользователя | 5 RPS | 700 мс | < 2% |

Запуск против локального nginx:

```bash
k6 run -e BASE_URL=http://localhost:8080 k6/search.js
k6 run -e BASE_URL=http://localhost:8080 k6/restaurant-card.js
k6 run -e BASE_URL=http://localhost:8080 k6/booking-read.js
```

Для облака тот же `BASE_URL` указывает на Ingress. Во время прогона смотрятся графики Grafana и срабатывание HPA: при устойчивом CPU выше 70% у gateway и restaurants число реплик растёт до 6. Лимиты запросов и пределов заданы в `k8s/apps.yaml`.
