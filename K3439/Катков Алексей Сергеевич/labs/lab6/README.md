# ЛР6. Мониторинг ВМ

На Linux-хосте с запущенным приложением скопируйте `.env.example` в `.env` и установите пароль Grafana. Укажите имя сети приложения в `APP_NETWORK`, если изменили имя Compose-проекта.

```bash
docker compose up -d
docker compose ps
```

Grafana доступна через SSH-туннель или приватный проброс порта 13000. Вход - `admin` и пароль из `.env`. Дашборд расположен в папке Recipes. Показатели Node Exporter относятся к Linux-хосту Docker. Порт 9100 не требуется открывать во внешнем firewall.

Если Docker Desktop не маршрутизирует `host-gateway` к Linux-ВМ, укажите в `.env` параметр `NODE_EXPORTER_GATEWAY` с адресом шлюза сети мониторинга из `docker network inspect recipes-observability_default` и повторите `docker compose up -d`.

Проверка доступности выполняется для четырёх HTTP-сервисов по `/ready`. Поле `container` позволяет выбрать контейнер в Loki. Чтобы проверить недоступность, остановите один сервис на учебном стенде и дождитесь `DOWN`; затем запустите его и проверьте восстановление.

Для проверки письма без внешнего SMTP запустите `docker compose -f compose.yaml -f mailpit.yml up -d`. Правило отправляет тестовое сообщение при `probe_success < 1` в течение 20 секунд. Сообщения доступны локально на порту 18025. Для реального SMTP укажите свои реквизиты и адрес получателя.
