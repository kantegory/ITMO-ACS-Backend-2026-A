# ДЗ10. Нагрузочные сценарии

Сценарий k6 использует отдельного тестового пользователя и один рецепт с комментарием. В нагрузочной части 50% запросов идут в список рецептов с фильтром, 30% - в карточку рецепта, 10% - в комментарии и 10% - в профиль по JWT. Запросы подготовки и очистки помечены `phase=fixture`.

```bash
k6 run -e BASE_URL=http://127.0.0.1:18081 -e PROFILE=baseline \
  -e SUMMARY_PATH=baseline.json load.js
```

| Профиль | Нагрузка | Назначение |
| --- | --- | --- |
| smoke | 2 запроса/с, 15 секунд | Проверка источника данных и API |
| baseline | 30 запросов/с, 60 секунд | Проверка SLO |
| stress | 30 → 240 запросов/с ступенями | Поиск границы SLO |
| autoscale | 30 → 350 запросов/с с плато 90 секунд | Проверка реакции HPA |

Цели для baseline: 30 запросов/с при нулевых dropped iterations, p95 < 250 мс, p99 < 600 мс и error rate < 1%. Это внутренние SLO. Фактическая продолжительность прогона включает подготовку и завершение, поэтому средний `http_reqs/s` в общей сводке может отличаться от частоты генератора.
