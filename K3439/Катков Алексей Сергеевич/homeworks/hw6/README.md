# ДЗ6. Доставка на ВМ

Триггер - push в `katkov-deploy` в форке курса. Workflow `Recipes CI and delivery` находится в `.github/workflows/recipes.yml`. Он собирает образы с SHA, запускает проверки и публикует архив образов.

После ручного развёртывания ЛР4 на ВМ нужен GitHub CLI с доступом к артефактам форка. Скрипт `../hw8/deploy-release.sh vm` выбирает последний успешный запуск, проверяет SHA-256 архива и обновляет контейнеры существующего проекта `recipes`. Проверка выполняется через nginx на порту 80. Для другого порта задайте `RECIPES_VM_URL`.

Запускать скрипт можно таймером systemd или cron раз в минуту от пользователя с доступом к Docker. Новый релиз применяется однократно. При ошибке проверки восстанавливается предыдущий тег. Смена схемы базы выполняется отдельно и должна быть совместима с откатом.
