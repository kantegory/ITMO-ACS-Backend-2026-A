К теме относится ДЗ7 (технический дизайн облачной инфраструктуры, срок 21.11.2026), а его результат напрямую используется в ЛР7 (облачное развёртывание, срок 05.12.2026).

- [01-cloud-models.md](./01-cloud-models.md) — модели обслуживания (IaaS/PaaS/CaaS/FaaS), модель общей ответственности, выбор уровня для проекта.

- [05-architecture-principles.md](./05-architecture-principles.md) — архитектурные решения, инфраструктура как код.
- [06-dz7-walkthrough.md](./06-dz7-walkthrough.md) — подробнее о ДЗ7.
