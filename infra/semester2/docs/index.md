# Поиск работы

Микросервисный backend для вакансий, резюме и откликов. Проект продолжает ЛР2–3 первого семестра; реализация — Kotlin, Java 17, Spring Boot 3.5.7, Spring Cloud Gateway, PostgreSQL 17, Kafka 3.8, Elasticsearch 8.15.

Документация описывает существующее приложение и инфраструктуру второго семестра. Проверки и ограничения зафиксированы в отчётах; наличие манифеста само по себе не означает, что облачное окружение уже развёрнуто.

Быстрый путь: [запуск](operations.md), [Swagger и сценарий Postman](api.md), [панели Grafana](monitoring.md).
